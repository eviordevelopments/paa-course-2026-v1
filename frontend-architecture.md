Build a production-ready, highly polished, responsive FRONTEND landing page for a Spanish-language online PAA preparation course.

IMPORTANT:
The attached reference images are the SINGLE SOURCE OF TRUTH for the visual design. Recreate the website from the references as accurately as possible. Do not interpret the design loosely, do not replace it with a generic education landing page, and do not simplify the decorative elements.

The final website should feel like the screenshots were transformed from a presentation into a modern interactive web landing page.

TECH STACK:

- React
- TypeScript
- Tailwind CSS
- Component-based architecture
- Use CSS animations and transitions
- Use Lucide icons or custom SVG where appropriate
- Frontend only for now
- No backend
- No authentication
- No database
- No real payment processing
- CTA buttons can visually work and scroll to the relevant section, but do not implement a real checkout
- Keep the project clean, reusable and easy to modify

The visual identity is:

- youthful
- academic
- friendly
- feminine/pastel
- handmade scrapbook / Pinterest / Canva editorial aesthetic
- premium but approachable
- playful without looking childish
- lots of pastel lavender, mint, cream, peach, yellow, pink and light blue
- dark navy handwritten accents
- large elegant serif headlines
- handwritten/script accent typography
- rounded cards
- paper textures
- subtle shadows
- masking tape decorations
- dotted backgrounds
- stickers
- doodles
- polaroid-style photographs
- organic blobs
- pastel gradients

DO NOT make this look like:

- a corporate SaaS website
- a conventional university website
- a generic Bootstrap landing page
- a dark dashboard
- a minimalist white-only landing page

The desktop experience should closely match the composition and visual density of the references.

Use generous whitespace but preserve the scrapbook decorations around the content.
